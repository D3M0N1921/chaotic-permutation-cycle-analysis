## 实现内容

**三种混沌映射**

| 映射 | 公式 | 混沌参数范围 | 默认值 |
|------|------|------------|--------|
| Logistic | x(n+1) = μ·x(n)·(1−x(n)) | 3.57 < μ < 4 | μ=3.99 |
| Tent | x(n+1) = μ·min(x(n), 1−x(n)) | 1 < μ < 2 | μ=1.99 |
| Sine | x(n+1) = μ·sin(π·x(n)) | 0 < μ < 1 | μ=0.99 |

**六组实验**

1. 单个置乱表的循环结构详细分析（N=100 & N=1000）
2. 平均阶 vs N 曲线（N=50~5000，与随机置换理论值对比）
3. 循环长度分布直方图
4. 种子敏感性（x₀ 附近 ±0.001 扰动）
5. 参数 μ 敏感性（在混沌区间内扫描）
6. 置乱质量评估（位移距离分布 + 不动点统计）

## 核心算法

**置乱表生成：** 选定混沌映射和种子 x₀ → 迭代 1000 轮丢弃暂态 → 继续迭代 N 轮 → 对混沌序列排序得到置乱索引。

**循环分解：** 从未访问元素出发沿 i → perm[i] 追踪至回到起点，遍历所有元素即得完整循环分解。

**阶计算：** 阶 = LCM(所有循环长度)，即置乱恢复为恒等映射所需的最少复合次数。
